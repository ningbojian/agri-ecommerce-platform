# 比赛版小程序（2021 计赛）

原生微信小程序（WXML/WXSS/JavaScript/JSON）的电商助农原型，覆盖：

- 乡村信息首页、捐赠/帮扶入口、新闻/政策；
- 电商助农：米面粮油、水果生蔬、茗茶干货、肉蛋水产分类 → 商品详情（Tmall web-view）；
- 乡村旅游目的地、地图探索、个人中心/求助/反馈等页面；
- 2021 年比赛版保留的全部页面和组件（未做功能删减）。

## 运行

1. 用微信开发者工具导入本目录。
2. AppID 使用 `touristappid`（或替换为你自己的测试 AppID）。
3. 项目已包含 `miniprogram_npm/`，通常不需要重新构建 npm。
4. 真实图片/商品数据是 2021 年的静态素材，部分外链可能失效；README 的截图来自当年的作品小结。

## 已知未完成项（后续增量）

- `app.js` 和登录/注册页使用 `wx.cloud`，当前 env 是 `YOUR_CLOUD_ENV_ID` 占位；需要配置真实云环境后才能使用登录/注册/云数据库。
- 商品购买是 `<web-view>` 跳转 Tmall，不是自建购物车/订单/支付。
- 页面路由已尽量补齐（`node scripts/validate-miniprogram.mjs competition-miniprogram`），但部分动态 `{{item.url}}` 和旧组件仍需在 DevTools 里逐页验证。
- 旧的快递查询页使用 `YOUR_APISHOP_API_KEY` 占位；接入前请换成你自己的 key，并注意第三方接口限制。
